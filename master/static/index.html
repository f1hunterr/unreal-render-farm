    Setting up a render computer

    1. On the master: run deploy\build_agent_package.ps1 once
    2. Copy dist\UnrealRenderFarm_agent to the render computer
    3. Double-click SETUP.bat and click Yes
    4. It appears under Registered Computers by itself
